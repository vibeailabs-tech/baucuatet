# Bầu Cua Tôm Cá 🎊

A Vietnamese Tết dice gambling game playable in any browser. No dependencies, no install — just one HTML file.

## Play instantly

Download or clone the repo, then open `index.html` in your browser:

```bash
git clone https://github.com/vibeailabs-tech/baucuatet.git
cd baucuatet
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

## How to play

1. Click one or more symbols on the board to select them
2. Choose a bet amount (+10, +50, +100, +500)
3. Click **Lắc!** to roll the 3 dice
4. Win if your symbol appears on 1, 2, or 3 dice — pays 1×, 2×, or 3× your bet
5. Click **🔇 Nhạc** (top-right) to toggle background music

You start with **1,000 xu**. Game resets when you run out.
